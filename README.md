# Dantel — Full-Stack Engineer Portfolio

A responsive Next.js App Router portfolio with a dark, violet-accented visual system, Framer Motion interactions, Lenis smooth scrolling, and an interactive terminal.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Personalize the portfolio

Before publishing, update the sample project descriptions, links, availability, and social profiles in `src/components/Projects.jsx` and `src/components/Navbar.jsx`. Update the contact email and social links in `src/components/Footer.jsx`.

The project cards currently use CSS-built product previews so they do not depend on external image services. Replace those previews with screenshots or video when project assets are available.

## Production checks

```bash
npm run lint
npm run build
```
